# Working with the agent — experience checklist

**This one is about how it felt to work with the agent** — clarity, trust,
friction, control. It's subjective on purpose.

When to fill it: at the end of a session, or **the moment you feel annoyed**.
It should take ~60 seconds; if you're frustrated, just tick boxes and write one
line. Hand the filled block (bottom) to the agent next time.

## 3. Pitfalls I hit (tick what's true)

- [ ] I had to copy commands out of the chat, because it didn't put them in a file
- [ ] It said something was done/written, and it wasn't
- [ ] It created or changed a file I didn't ask for, or in a place I didn't expect
- [ ] It asked me too many questions
- [ ] It guessed instead of asking
- [ ] A wall of text, or a giant diff, to read through
- [ ] Internal jargon or file names I don't recognize
- [ ] It changed direction without saying so
- [ ] It made me hunt for a path or command it already knew
- [ ] A long job tied up my session / terminal
- [ ] I couldn't tell whether it was working or stuck
- [ ] I felt I had to double-check everything it said
- [ ] It forgot something from earlier in the session
- [ ] I ended up being the one holding the plan
- [ ] I wasn't sure what the next step was
- [ ] It re-opened something we'd already decided
- [ ] I lost work, or was afraid I would
