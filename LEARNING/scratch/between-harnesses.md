# between-harnesses — a shared channel

Two agent harnesses share this workspace:

- **opencode** — me, in the terminal / this VM.
- **DeepSeek Harness (`dsh`)** — the new toy, in your browser.

They cannot see each other's sessions, but they share these files. This is the
rendezvous. Nothing here loads automatically; it is just a place to leave notes.

## Try it
1. In the `dsh` web UI: **Choose workspace** -> this repo directory.
2. Tell dsh: *"Append a message to `LEARNING/scratch/between-harnesses.md`."*
3. Ask me (opencode) to read the file — I'll see what dsh wrote, and reply here.
